# 摸鱼阅读器

一个为「上班/上课摸鱼看小说」设计的小浮窗。两个版本，功能相同，任选顺手的使用。

> 本仓库**只包含代码**，不含任何小说文本。书籍请自行准备（详见下方「自备书籍」）。

## 快速开始

### 桌面浮窗版（推荐，真悬浮）

双击 **`摸鱼阅读器.bat`** 即可。

- 窗口永远浮在所有程序最上层，无边框、半透明，低调的浅灰配色，看起来像编辑器的一个面板
- **侧边收条**：鼠标不在浮窗上时，自动缩成屏幕**左**边一道几像素的细线（几乎看不见）；鼠标一碰就展开。默认开启，按 `Ctrl+E` 开关
- 刚打开时保持展开，鼠标真正进过窗口一次之后，才启用「离开就收起」
- 按 `Ctrl+H` 一键消失，老板来了瞬间无痕

### 网页版（样式更精致）

双击 **`web/index.html`** 用浏览器打开。

- 毛玻璃半透明、圆角阴影，贴在屏幕角落非常好用
- 支持**把 txt 文件直接拖进窗口**导入小说
- 阅读进度存在浏览器里，下次打开继续读

## 自备书籍

仓库不含任何小说文本，请按下面任一方式准备：

**方式一（推荐）**：桌面版按 `Ctrl+O`，网页版把 txt 直接拖进窗口。

**方式二**：把 txt 放进 `books/` 目录，然后照 `books/books.json.example` 的格式建一个
`books/books.json` 索引，重启程序即可。

```json
[
  { "id": "书名", "title": "书名", "file": "书名.txt", "chars": 12345 }
]
```

> 想用公有领域作品练手，可以去 [Project Gutenberg](https://www.gutenberg.org/) 找
> 鲁迅《呐喊》《徬徨》《阿Q正传》等（作者逝世超过 50 年，已进入公有领域）。

## 快捷键（两版通用）

| 按键                 | 功能                       |
| ------------------ | ------------------------ |
| `空格`               | 开始 / 暂停 自动滚动             |
| `Ctrl + ↑ / ↓`     | 字号 变大 / 变小               |
| `Ctrl + ← / →`     | 自动滚动 变慢 / 变快             |
| `Ctrl + 滚轮`        | 调整背景不透明度                 |
| `Ctrl + D`         | 伪装模式（隐藏边栏，只剩正文）          |
| `Ctrl + E`         | 侧边收条开关（鼠标移入才展开）          |
| 拖窗口边缘/角落           | **缩放窗口大小**（桌面版 & 网页版都支持） |
| 双击标题栏 / `F11`      | 最大化 / 还原（桌面版）            |
| `Ctrl + H`         | 老板键：瞬间隐藏 / 恢复            |
| `Ctrl + Q` / `Esc` | 关闭浮窗（桌面版，右上角 ✕ 也行）       |
| `Ctrl + O`         | 导入本地 txt（桌面版）            |
| `Ctrl + B`         | 书库（桌面版）                  |
| `S`                | 设置面板（网页版）                |

## 阅读进度

**自动记忆，精确回到原处。** 关掉再打开，会回到你上次停下的那一句，并提示"已回到上次阅读处"。

- 进度按**字符位置**记录（不是按百分比），所以即使你调整了窗口大小、字号，回来还是同一句话
- 滚动停下 1.5 秒后自动存档，另有 20 秒定时保存，正常关窗也会存
- 每本书的进度**各自独立**，来回切书互不影响
- 换新电脑或删掉 `config.json` 会丢失进度

## 操作

- **移动**：按住标题栏 / 状态栏 / 正文区拖拽
- **缩放**（网页版）：拖窗口右下角或左右边缘
- 进度自动保存：关掉再开，接着上次的位置继续

## 目录结构

```
moyu-reader/
├── 摸鱼阅读器.bat      ← 桌面版一键启动（双击这个）
├── 启动(诊断).bat      ← 打不开时用这个，会显示报错
├── launch.py           ← 启动器（负责找 Python + 捕获报错）
├── moyu_reader.py      ← 桌面版源码（tkinter）
├── books/
│   └── books.json.example  ← 书库索引格式示例
├── web/
│   └── index.html      ← 网页版（双击打开）
└── tools/
    ├── clean_books.py  ← 文本清洗脚本（Gutenberg→简体重排）
    ├── test_dock.py    ← 桌面版自动化测试（39 项断言）
    └── probe_web.js    ← 网页版无头浏览器验证（CDP）
```

## 环境要求

- **桌面版**：Python 3.12+（需带 tkinter，python.org 官方安装包默认包含）
  - 只用标准库，无需 `pip install` 任何东西
- **网页版**：现代浏览器即可，零依赖

## 开发

```bash
# 桌面版测试（需要能建 GUI 的环境）
python tools/test_dock.py

# 网页版验证（需要本机装了 Chrome，会启动无头浏览器）
cd web && node ../tools/probe_web.js
```
